# MafA Discovery: Documentation Hub & Developer Guide

Welcome to the documentation portal for the **MafA Discovery Integrated Genomic Explorer**.

---

### User Documentation

* **[User Guide](https://byandell.github.io/MafADiscovery/docs/user_guide.html)** ([source](https://github.com/byandell/MafADiscovery/blob/main/guides/user_guide.md))  
   Complete guide to interpreting the Manhattan macro view, Locus micro schematic, coding variant consequence scoring (`phastCons`), QTL confidence intervals, and navigation modes.

* **[About MafA Discovery](https://byandell.github.io/MafADiscovery/docs/about.html)** ([source](https://github.com/byandell/MafADiscovery/blob/main/guides/about.md))  
   Biological background on MafA transcription factor dynamics in C57BL/6J and SJL/J mouse models, collaborative research consortium, and integrated data assets.

### Developer & Technical Documentation

* **[Master Developer Guide](https://byandell.github.io/MafADiscovery/docs/DEVELOPER.html)** ([source](https://github.com/byandell/MafADiscovery/blob/main/DEVELOPER.md))  
   Overall technical guide covering repository architecture, mouse GRCm39 coordinate mapping, reactive lifecycle, coding standards, and deployment rules.

* **[F2 Glycemic QTL Integration](https://byandell.github.io/MafADiscovery/docs/qtlanalysis.html)** ([source](https://github.com/byandell/MafADiscovery/blob/main/guides/qtlanalysis.md))

* **[App Redesign & Reactivity](https://byandell.github.io/MafADiscovery/docs/redesign.html)** ([source](https://github.com/byandell/MafADiscovery/blob/main/guides/redesign.md))

* **[Publishing & Deployment](https://byandell.github.io/MafADiscovery/docs/publishapp.html)** ([source](https://github.com/byandell/MafADiscovery/blob/main/guides/publishapp.md))  
   Shinylive (webR) static WebAssembly deployment architecture, performance benchmarks, and automated GitHub Actions CI configuration.

* **[Legacy Prototypes](https://byandell.github.io/MafADiscovery/docs/shinyapp.html)** ([source](https://github.com/byandell/MafADiscovery/blob/main/guides/shinyapp.md))
